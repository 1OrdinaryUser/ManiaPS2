PUT YOUR OWN Data.rsdk HERE
===========================

Copy the file  Data.rsdk  from your own installed copy of Sonic Mania Plus into this folder, then run build.bat.

  Steam:  <Steam library>\steamapps\common\Sonic Mania\Data.rsdk   (next to SonicMania.exe)

This repository does not contain the game data and never will. Only the Steam PC version of Sonic Mania Plus has been tested.
Everything in this folder except this file is ignored by git
